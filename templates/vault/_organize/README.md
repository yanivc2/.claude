# _organize — תוצרי סבבי הארגון

הבית של `/organize-folders`:

- `scan-YYYY-MM-DD.md` — אינוונטר קריאה-בלבד של אזורי הארגון.
- `proposal-YYYY-MM-DD.md` — רשימת ההעברות המוצעת, ממתינה לאישור.
- `apply-log-YYYY-MM-DD.md` — יומן הביצוע בפועל, מנה אחרי מנה.
- `trash/` — "מחיקות" מבוימות: קבצים שאושרו להסרה מחכים כאן. הריקון ידני
  בלבד, אחרי בדיקה. שום דבר כאן לא נמחק אוטומטית.
