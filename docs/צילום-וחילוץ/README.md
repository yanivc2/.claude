# צילום וחילוץ — תיק הפרויקט

כל מה שקשור לצילום חשבוניות מהטלפון ולחילוץ הנתונים מהן: איך זה עובד, מה נחקר, מה הוחלט,
ומה עוד פתוח. זה המסמך שמתחילים ממנו.

> **הערה על שם התיקייה:** ביקשת "צילום וחילוץ". השם נשמר עם מקף במקום רווח
> (`צילום-וחילוץ`) כדי שנתיבים בשורת פקודה, ב-git ובסקריפטים לא ידרשו מרכאות בכל פעם.

## מה יש כאן

| תיקייה | מה בפנים |
|---|---|
| [`קטלוגים/`](קטלוגים/) | קטלוג-העל: מאיפה הנתונים, איך מזהים מוצר, ואיך מעדכנים את הקובץ |
| [`טכנולוגיה/`](טכנולוגיה/) | איך הסורק בנוי, איך החילוץ עובד, ומה באמת קובע את העלות |
| [`מחקרים/`](מחקרים/) | המחקרים שנעשו, עם הנתונים עצמם — כולל תקלות שנפתרו והסיבה האמיתית שלהן |

**העיקרון שלא משתנה:** המערכת לעולם לא כותבת נתון כספי בלי שאדם אישר. כל דבר שהמודל לא
בטוח בו, וכל דבר שהקטלוג מציע — מסומן ומוצג, ולא מוחל לבד.

## המצב היום

| רכיב | מצב |
|---|---|
| צילום מהטלפון | עובד. הצילום האוטומטי עדיין בכיול |
| חילוץ באמצעות המודל | עובד |

| זיהוי לפי ברקוד מקוצר | עובד — ראה [`קטלוגים/זיהוי-מוצר.md`](קטלוגים/זיהוי-מוצר.md) |
| פרופיל לכל ספק | מתוכנן |

## מה עוד פתוח

- **הצילום האוטומטי לא נורה בשטח.** המנוע תקין (נבדק בדפדפן אמיתי); הסף שחוסם עדיין לא זוהה
  סופית. מסך האבחון באפליקציה נועד בדיוק לזה.
- **פרופיל לכל ספק** — כל ספק מדפיס חשבונית אחרת, ולכן ההנחיות למודל צריכות להשתנות לפי הספק.
- **קטלוג מרשת נוספת.** ששת סניפי שופרסל נתנו תשואה פוחתת (ראה המחקר); רשת אחרת תרחיב באמת.
