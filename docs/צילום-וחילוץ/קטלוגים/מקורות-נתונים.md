# מקורות הנתונים לקטלוג-העל

## 1. חוק שקיפות המחירים (המקור הפומבי)

כל רשת עם 3 סניפים ומעלה מחויבת לפרסם קובצי מחירים יומיים בפורמט XML דחוס.
זה מקור חוקי, חינמי ויציב.

| רשת | נקודת גישה | הערה |
|---|---|---|
| **שופרסל** | `prices.shufersal.co.il` — ללא התחברות | זה מה שמיושם היום |
| Cerberus (רמי לוי, אושר עד, חצי חינם ועוד) | `url.publishedprices.co.il` | שמות משתמש פומביים, סיסמה ריקה |

**הנקודה שגילינו במדידה:** הוספת סניפים של אותה רשת נותנת תשואה פוחתת במהירות.

| סניף | פריטים בקובץ | חדשים למיזוג |
|---|---|---|
| 1 | 6,000 | **6,000** |
| 2 | 6,929 | 1,430 |
| 3 | 5,818 | 235 |
| 4 | 6,655 | 225 |
| 5 | 6,393 | 173 |
| 18 | 6,241 | 156 |

הסניף השני הוסיף 1,430 ברקודים; ארבעת הנותרים יחד הוסיפו 789. **סניפי שופרסל מחזיקים כמעט את
אותו מגוון.** מי שרוצה להרחיב באמת צריך **רשת אחרת**, לא עוד סניף.

### מלכודות שנתקלנו בהן

- הכתובת שעובדת היא `FileObject/UpdateCategory?catID=2&storeId=0`. הפרמטר `?catID=` על כתובת
  השורש פשוט לא מסנן.
- שם הקובץ הוא `PriceFull<רשת>-<תת-רשת>-<סניף>-<תאריך>-<שעה>.gz` — שלוש קבוצות ספרות, לא שתיים.
- **שופרסל כותבת את התג `ManufactureName`** (בלי r). הפענוח מקבל את שתי הצורות; בלי זה כל
  6,392 הפריטים הוצגו כ"ללא יצרן".
- `כללי`, `---` ו-`לא ידוע` הם ערכי זבל בעמודת היצרן ומנוקים אקטיבית.

## 2. קובץ שהבעלים מספק (המקור העשיר)

קובץ CSV/XLSX ידני, גדול ואיכותי יותר:

| | קובץ הבעלים | שופרסל (6 סניפים) |
|---|---|---|
| שורות | **38,334** | 8,219 |
| ברקודים ייחודיים | 38,280 | 8,219 |
| יצרנים | 2,933 | 1,351 |
| ברקודים בפורמט תקין | 38,279 (100%) | — |

עמודות בקובץ: `ברקוד, שם, מקט, יח' אריזה, יצרן, כמות, יחידת מידה, שקיל, ארץ ייצור, מחיר מדף,
מחיר מדף מינ', מחיר מדף מקס', מספר סניפים, ברקוד תקין`.

**נשמרות:** ברקוד, מק"ט, שם, יח' אריזה, יצרן (החלטת הבעלים).
**לא נשמרות:** טווח מחירים, מספר סניפים, ארץ ייצור, שקיל.

### שתי אזהרות על הקובץ הזה

1. **עמודת `מקט` מלאה ב-55 שורות בלבד** מתוך 38,334. העמודה קיימת במסד, אבל בפועל היא כמעט ריקה.
2. **`כללי` (7,337 שורות) ו-`---` (1,886) הם ערכי זבל** בעמודת היצרן — יחד עם 1,551 ריקות,
   כ-28% מהשורות יגיעו בלי יצרן אמיתי. הניקוי הקיים מטפל בזה.

## 3. מה נבדק ונפסל

- **OpenIsraeliSupermarkets** (GitHub) — סקרייפר ופענוחים ב-Python עם פרסום יומי ל-Kaggle.
  אין API מתארח ואין מערך נתונים מוכן להורדה, והאפליקציה היא Node בלבד. לכן נכתב יבואן קטן משלנו.
- **רשימת הרשתות הרשמית ב-gov.il** (`cpfta_prices_regulations`) — מחזירה 403 מהסביבה שלנו;
  השתמשנו במראה של consumers.org.il.

## הבחירה המעשית

| רוצים | לעשות |
|---|---|
| קטלוג טוב עכשיו, בלי תלות באף אחד | להעלות את קובץ הבעלים במסך ההגדרות |
| רענון אוטומטי שבועי בלי מגע יד | ה-Action של שופרסל (2 סניפים מספיקים) |
| כיסוי מרבי | קובץ הבעלים **וגם** רשת שנייה מ-Cerberus |
