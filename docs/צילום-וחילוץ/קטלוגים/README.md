# קטלוג-העל

טבלה אחת, `master_catalog`, שמכילה מוצרי צריכה לפי ברקוד: שם רשמי, יצרן, תכולה ואריזה.
היא **מקור אמת לזהות מוצר** — לא למחירים ולא לספקים.

## למה היא קיימת

חשבונית מדפיסה "הומוגני 1% דל". זה לא שם מוצר שאפשר לנהל איתו קטלוג, להשוות מחירים לאורך זמן,
או לזהות שאותו מוצר הגיע משני ספקים. הקטלוג הופך את זה ל"חלב מפוסטר 1% בקרטון 1ל · תנובה"
עם ברקוד מלא.

## מה יש בטבלה

| עמודה | מקור | הערה |
|---|---|---|
| `barcode` | הקובץ | מפתח הזהות, ייחודי |
| `name` | הקובץ | השם הרשמי |
| `manufacturer_name` / `manufacturer_norm` | הקובץ | הנרמול משמש לקיבוץ בלבד |
| `unit_qty`, `quantity`, `qty_in_package` | הקובץ | תכולה ואריזה |
| `retail_price` | הקובץ | **מחיר לצרכן** — לתצוגה בלבד |
| `source_chain`, `source_store`, `imported_at` | הייבוא | מקור ומועד |

## שלושה דברים שהקטלוג הזה **אינו**

1. **הוא לא מחירון קנייה.** `retail_price` הוא מחיר מדף לצרכן. אסור להשוות אליו מחיר מספק
   ולהסיק חריגה — המרווח הוא בדיוק העסק.
2. **הוא לא רשימת ספקים.** `manufacturer_name` הוא היצרן. תנובה מייצרת, אבל המפיץ בפועל
   יכול להיות אחר לגמרי.
3. **הוא לא שלם.** אין בו מוצרי שקילה, מוצרים פנימיים של רשת, ופריטים שאף רשת לא מדווחת.
   מוצר שלא נמצא בקטלוג הוא מצב תקין — לא שגיאה.

## איפה זה בקוד

- `src/catalog/importMasterCatalog.js` — כלי שורת הפקודה
- `src/routes/products.js` + `src/views/products/master.ejs` — מסך העיון (`/products/master`)
- `.github/workflows/ap-control-catalog-import.yml` — ייבוא בלחיצה מ-GitHub
