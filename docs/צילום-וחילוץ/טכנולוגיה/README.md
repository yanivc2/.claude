## עקרונות שחוזרים בכל הרכיבים

1. **אדם מאשר, תמיד.** אין מסלול שבו נתון כספי נכתב בלי אישור.
2. **כשל הוא מצב, לא חריגה.** כל בעיה הופכת להודעה בעברית ולכפתור "נסה שוב".
3. **הידרדרות במקום חסימה.** אין מצלמה? יש מצלמת מכשיר. אין OpenCV? יש כפתור ידני.
4. **מה שאי אפשר לאבחן — אי אפשר לתקן.** כל שגיאת API נרשמת עם הקוד שלה.
5. **בלי תלויות מיותרות.** פענוח ה-XML, ספירת עמודי PDF ובדיקת ספרת הביקורת נכתבו ידנית.
