# סוכן סנכרון הבנק — התקנה על מחשב המשרד

הסוכן מתחבר להפועלים לעסקים בשם מי שלחץ "סנכרן" באפליקציה, ממתין לקוד ה-SMS שהוזן
באפליקציה, ושולח את התנועות של כל החשבונות. **הוא חייב לרוץ כדי שכפתור הסנכרון יעבוד.**

## התקנה (פעם אחת, כ-10 דקות)

1. **Node.js** — להוריד ולהתקין את גרסת LTS מ-https://nodejs.org (22 ומעלה).
2. **הקוד** — ב-GitHub, בריפו `ap-control`: ‏Code ← Download ZIP. לחלץ לתיקייה קבועה:
   - Windows: `C:\ap-control`
   - Mac: `~/ap-control`

   🔴 **לא לשולחן העבודה ולא ל"מסמכים"** — ב-Windows הן מסונכרנות לרוב ל-OneDrive, וב-Mac
   ל-iCloud. קובץ ההגדרות מכיל סיסמאות בנק, ואסור שיעלה לענן.
3. **התקנת הסוכן** — לפתוח טרמינל (Windows: ‏`cmd`) בתיקייה `agent` ולהריץ:
   ```
   npm install
   ```
   (מוריד דפדפן ייעודי, כ-170MB.)
4. **הגדרות** — להעתיק את `config.example.json` לקובץ חדש בשם `config.json` ולמלא:
   - `agentSecret` — אותו ערך בדיוק כמו `BANK_AGENT_SECRET` ב-Vercel.
   - `logins` — שורה לכל מי שיסנכרן. **המפתח** הוא שם המשתמש באפליקציה — הוא מופיע בכרטיס
     הסנכרון בדף התאמת בנק ("המפתח שלך במחשב המשרד"). הערך: קוד המשתמש והסיסמה **שלו** בבנק.
     ה-SMS יישלח לטלפון שרשום אצל הבנק לאותו קוד משתמש.
   - `accountIds` — אפשר להשאיר ריק; החשבונות מתגלים לבד.
5. **בדיקה** —
   ```
   npm run check
   ```
   צריכים להופיע שלושה ✓: קובץ ההגדרות, חיבור לאפליקציה, הדפדפן עולה. הבדיקה **לא** מתחברת לבנק.
6. **הפעלה** — לחיצה כפולה על `start-agent.bat` (Windows) או `start-agent.command` (Mac).
   **להשאיר את החלון פתוח.** בכרטיס הסנכרון באפליקציה יופיע "● מחשב המשרד מחובר".

## הפעלה אוטומטית כשהמחשב נדלק

- **Windows:** ‏`Win+R` ← `shell:startup` ← להעתיק לשם קיצור דרך ל-`start-agent.bat`.
- **Mac:** הגדרות מערכת ← כללי ← פריטי התחברות ← `+` ← לבחור את `start-agent.command`.

## הוספת משתמש (למשל המזכירה)

להוסיף שורה ל-`logins` ב-`config.json` — בלי להפעיל מחדש, הסוכן קורא את הקובץ בכל בקשה.

## אבטחה

- `config.json` מכיל סיסמאות בנק. הוא נשאר **רק במחשב הזה**: לא נשלח לאפליקציה, לא נשמר במסד,
  ולא נכתב ללוג. המחשב צריך סיסמת כניסה.
- קוד ה-SMS עובר דרך האפליקציה ונמחק מהמסד ברגע שהסוכן לוקח אותו.
- הסוכן מנסה **פעם אחת** בכל סנכרון — גם להתחברות וגם לקוד. הבנק נועל גישה אחרי כמה כשלונות.

## תקלות

| מה רואים | מה לעשות |
|---|---|
| "מחשב המשרד לא מחובר" | לוודא שהמחשב דלוק ושחלון הסוכן פתוח |
| `401 הסוד שגוי` | `agentSecret` שונה מ-`BANK_AGENT_SECRET` ב-Vercel |
| `503 הסוכן כבוי` | לא הוגדר `BANK_AGENT_SECRET` ב-Vercel (ואחרי הגדרה — Redeploy) |
| "אין פרטי בנק למשתמש X" | להוסיף את X ל-`logins` |
| "הבנק לא קיבל את הקוד" | הקוד הוקלד שגוי או פג תוקף — ללחוץ "סנכרן" שוב |
| "הדפדפן לא עלה" | להריץ `npm run check` ולראות מה נכשל |
